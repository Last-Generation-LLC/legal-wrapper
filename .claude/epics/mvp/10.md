# Assistant UI (thread, composer, citations)

## Description

Build the full Assistant screen from the handoff: the message thread (role tags,
timestamps, token accounting, streaming indicator), the composer (⌘↵ to send,
Attach), the context strip with per-doc pills, message actions (copy, regenerate,
edit prompt), and the citation + confidence rendering (pills + colored dot).

## Acceptance Criteria

- [x] Message thread matches the handoff (max-width 780px, role tags, mono metadata).
- [x] Streaming responses render live with the pulsing-dot drafting indicator.
- [x] Composer: textarea, ⌘↵ send + Send button, Attach, mono hint.
- [x] Context strip shows one blue pill per selected doc; updates live with selection.
- [x] Message actions: Copy, Regenerate, Edit prompt.
- [x] Citation pills (`DocName §X · p.N`) and confidence dot render per contract.

## Decisions

- Spec/spec-review skipped by user decision (2026-06-12): the Claude Design
  handoff (`design_handoff_legal_wrapper/README.md` + `components/assistant.jsx`)
  is the authoritative spec for this task. Plan phases skipped too — proceed
  straight to implementation.
- Chat persistence: OUT of scope for #10. Thread is in-memory (resets on
  reload). Persistence captured as a follow-up task.
- "Edit prompt" action: ChatGPT-style — edit the originating user message,
  truncate the thread after it, and regenerate.
- Unverified citations: verified pills render blue (ctx tone per handoff);
  unverified pills render in the amber/warn tone with an "unverified" hint.
- System-prompt panel is task #11, NOT part of #10, even though the mockup
  includes it.
- Confidence dot on assistant messages uses the same thresholds as the Review
  grid contract (green >0.92, amber >0.85, else red), placed in the message
  metadata line.

## Notes

- Largest UI task; uses AI SDK `useChat`. Visual fidelity → review gate on.
- Consumes the shared `selectedDocs` state from the sidebar (005).
- Citation pills are display-only (no click-to-source) per scope.

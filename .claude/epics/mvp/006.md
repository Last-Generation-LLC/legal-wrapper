# Anthropic client + wrapper system prompt

## Description

Set up the Anthropic SDK client and the wrapper layer that is core to the thesis:
a tuned legal-workflow system prompt containing a literal `{{DOCUMENTS}}` token,
plus the server-side composition that replaces that token with the full text of
the selected documents on each call. Pin the model IDs after verifying them
against live Anthropic docs.

## Acceptance Criteria

- [ ] Anthropic SDK client configured from `ANTHROPIC_API_KEY`.
- [ ] Model IDs for Assistant (Opus) and Review (Sonnet) verified against live
      docs and pinned in one config location (the mock "4.5" labels are placeholders).
- [ ] A documented, tuned legal system prompt with a `{{DOCUMENTS}}` token.
- [ ] Server-side composer replaces `{{DOCUMENTS}}` with selected-doc text.
- [ ] Token counting available for context-meter accuracy.

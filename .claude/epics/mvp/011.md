# Review cell API + prompt caching

## Description

Build the per-cell Review API: accept `{ doc, columnPrompt }`, compose the
wrapper with the document text, call Claude (Sonnet), and return
`{ value, confidence, citation }` per the contract. **Enable Anthropic prompt
caching on the document text** so repeated cells against the same document pay a
fraction of input cost — this is load-bearing, not polish.

## Acceptance Criteria

- [ ] `POST` per-cell route accepts a document + a column prompt.
- [ ] Document text marked as a cache breakpoint; subsequent cells against the
      same doc register cache hits (verified via response usage fields).
- [ ] Returns value + confidence + citation per the 007 contract.
- [ ] Uses Sonnet; single-shot call.
- [ ] Errors return a debuggable message (e.g. "parse error: §7 contains table").

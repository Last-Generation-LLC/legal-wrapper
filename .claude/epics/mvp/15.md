# CSV export of the grid

## Description

Add the "CSV" button that dumps the current Review grid to a CSV file — rows =
documents, columns = prompts, cells = answer values.

## Acceptance Criteria

- [x] "CSV" button exports the grid as a downloadable `.csv`.
- [x] Rows are documents, columns are prompt titles, cells are answer values.
- [x] Values with commas/newlines/quotes are correctly escaped.

## Decisions

- Autonomous fast path approved by user (2026-06-12, "go for ... 15").
- Per prompt column the CSV emits THREE columns: the value, "<title> · confidence",
  and "<title> · citation" — confidence/citation are the product's differentiating
  data and belong in the export. First column is "Document" (docLabel).
- Cell rendering: done → value/confidence/citation; error → "error: <message>"
  in the value column; idle/running → empty.
- Escaping: RFC 4180 (quote fields containing comma/quote/newline, double the
  quotes) PLUS a formula-injection guard — values starting with = + - @ or tab
  get a leading apostrophe. Cell text is model-derived from untrusted documents;
  a crafted doc could otherwise smuggle =HYPERLINK(...) into Excel.
- A UTF-8 BOM is prepended so Excel renders § and other non-ASCII correctly.
- Download is pure client-side: Blob + temporary object URL + <a download>,
  filename review-grid-YYYY-MM-DD.csv. Button is the handoff's ghost "CSV"
  in the TopBar, disabled when there are no rows or no columns.

# Token-ceiling guardrails

## Description

Enforce the no-RAG context ceiling everywhere it matters: a warning as the
combined selected-document tokens approach ~180k, and a clear, blocking error
(not a silent bad call) when a request would exceed the window — in both the
Assistant and the Review API paths and their UIs.

## Acceptance Criteria

- [ ] Combined selected-doc token total is visible and warns as it nears ~180k.
- [ ] Assistant blocks the call past the ceiling with a clear message.
- [ ] Review blocks affected cells past the ceiling with a clear per-cell error.
- [ ] No silent truncation or silently failing calls.

## Notes

- This is the mitigation for the PRD's "Context ceiling" risk — the no-RAG
  approach has a hard wall, not graceful degradation.
- Cross-cutting: touches both API routes and both UIs → conflicts_with several.

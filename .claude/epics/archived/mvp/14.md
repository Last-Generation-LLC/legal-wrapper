# Cell inspector + regenerate

## Description

The bottom inspector drawer that opens when a `done` cell is selected: full cell
value, the column's full prompt, confidence and citation pills, and action
buttons (Regenerate, Edit prompt, View source). Regenerate re-runs that single
cell via the Review API.

## Acceptance Criteria

- [ ] Selecting a `done` cell opens the inspector with value, confidence pill, citation pill.
- [ ] Right column shows the full prompt for that column.
- [ ] Regenerate re-runs the single cell and updates it in place.
- [ ] Active cell gets the amber outline; inspector updates as selection changes.

## Notes

- Matches handoff "Inspector Drawer" spec.
- "View source" is a stub for now — click-to-source-PDF is out of scope.
- Edits the Review page → conflicts_with: 012.

## Decisions

- **[plan] Inspector is an in-flow bottom drawer** — a `flex-none` panel under the
  grid scroll area, not an overlay/portal. Simpler, no z-index/focus-trap work, and
  the grid stays visible above it.
- **[plan] Drawer shows all citations with their verbatim quotes** — not the grid
  cell's compact first-citation tag. The inspector is the "full answer" view, so it
  surfaces every supporting quote (transparent-prompts thesis).
- **[plan] Regenerate uses a dedicated `regenerateCell` runner** — no cache-warming,
  no semaphore (single cell, no fan-out). ~6 lines mirror `runGrid`'s per-cell logic;
  accepted minor duplication, isolated and unit-tested, to avoid touching the
  warm-skip path in `runGrid`. Regenerate is disabled while a "Run all" is in flight.
- **[plan] Shared `citationLabel` extracted to `doc-display.ts`** — the Assistant's
  local copy is replaced by the shared one (pure refactor, Assistant tests guard it),
  so both tabs format citation pills identically.
- **[plan] Selection invalidates** — the drawer closes if its column is deleted or
  its row is deselected in the sidebar; it stays open across regenerate (running→done).
